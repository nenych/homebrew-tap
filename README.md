# homebrew-tap

Homebrew formulae for my projects.

```
brew install nenych/tap/<formula>
```

| Formula | Installs | Project |
|---|---|---|
| `beamctl` | command-line control for a Logitech Litra Beam LX light | [nenych/beamctl](https://github.com/nenych/beamctl) |

The formulae build from the tagged source releases; each project's release workflow updates its formula here.
